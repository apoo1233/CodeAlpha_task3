# Data Visualization – CodeAlpha Internship

## 1. Project Overview

This project was completed as **Task 3 – Data Visualization** during my **Data Analytics Internship at CodeAlpha**.

The objective of this project is to represent data visually using Python and appropriate visualization techniques. The project focuses on transforming raw data into meaningful visual representations that make patterns, trends, comparisons, and relationships easier to understand.

Various charts and graphs were created using Python libraries such as Matplotlib and Seaborn.

## 5. Data Visualization Techniques

The project includes different types of visualizations to represent the data effectively.

### 5.1 Bar Chart

Bar charts are used to compare values across different categories.

### 5.2 Histogram

Histograms are used to understand the distribution of numerical data.

### 5.3 Box Plot

Box plots are used to examine the distribution, spread, and potential outliers in numerical variables.

### 5.4 Scatter Plot

Scatter plots are used to identify relationships between two numerical variables.

### 5.5 Correlation Heatmap

A correlation heatmap is used to visualize relationships between numerical variables and identify strongly correlated features.

### 5.6 Count Plot

Count plots are used to display the frequency of observations across categorical variables.
